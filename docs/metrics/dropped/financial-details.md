# Optional Financial Details — removed from first-filter screening

Gross Margin, Price/Sales and FCF Yield require business-model, capital-intensity and valuation context. The optional Financial Details section is removed from the first-filter UI.

Raw financial figures, calculation code, fiscal periods and source identifiers remain available to Analyze with AI. Excluded from visible cards, filters, presets, rankings and automatic scores. See the [metric index](../README.md).

# Optional Financial Details

Gross Margin, Price/Sales and FCF Yield are expanded details only, without qualitative ratings or ranking contributions. Each shows source identifiers, period, formula and dates. Gross Margin uses quarterly gross profit / revenue; Price/Sales uses current market cap / compatible TTM revenue; FCF Yield uses compatible TTM FCF / current market cap × 100. Require positive revenue or market-cap denominators, compatible currency and a fresh market quote. Financial-business FCF yield remains Unknown. Unknown is never zero.

These figures are context; weighted-average diluted shares used for market cap, vendor adjustments, capex definitions and stale statements can limit interpretation. Provenance is not independent verification.
