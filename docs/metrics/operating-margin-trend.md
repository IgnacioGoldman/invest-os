# Operating Margin Trend

`latest fiscal-quarter operating margin − operating margin in the same fiscal quarter last year`, in **percentage points**.

Labels use the signed change: **Improving** >0 pp; **Stable** =0 pp; **Declining** <0 pp. A numerical tolerance of 1e−10 pp only removes floating-point round-off at zero; it is not a materiality or investment threshold. Classification uses the unrounded calculation. A positive sign indicates improving operating performance, not investment attractiveness.

Both margins must independently pass the [operating-margin input checks](operating-margin.md), have matching currencies and definitions, and use unique equivalent fiscal quarters with period ends 350–380 days apart. Validate the latest report's 140-day freshness; the year-ago comparison is deliberately historical. Exclude proxy operating income and non-comparable financial sectors. A missing prior quarter hides only the trend card; a valid current Operating Margin can remain visible. Missing current data hides both.

For the saved GOOG SEC facts: Q2 2026 margin is `40,770 / 119,796 × 100 = 34.03285585%`; Q2 2025 is `31,271 / 96,428 × 100 = 32.42937736%`. Trend is **+1.60347850 pp · Improving**. Values are millions of USD from the saved SEC Companyfacts observations, not substituted estimates.

Preserve both periods, the four source inputs, as-of date, formula and freshness deadline. Source identifiers establish provenance; the app does not claim independent verification of financial statements.
