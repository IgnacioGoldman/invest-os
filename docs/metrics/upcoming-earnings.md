# Upcoming Earnings

Context only, with neutral styling. Extract the actual source event date or expected date window and calculate `event/window-start date − current UTC date` on each load. Display the date/window, days remaining, source and collection date. Yahoo calendar values are estimates unless an issuer confirmation is supplied. Past or same-day events, missing source dates and calendar inputs older than seven days are hidden; cached day counts are never presented as current.

Existing timing labels remain This week (1–7 days), Next 30 days (8–30), Later (>30), and Unknown. These are timing categories, never positive stock signals or scores.

An absent or invalid source date omits the card and its detail panel. Source type (expected calendar date versus issuer-confirmed date) remains in the expandable evidence; card styling is neutral.
