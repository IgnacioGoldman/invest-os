# Upcoming Earnings

## What it means?

_When is the company expected to report its next earnings?_

Shows how soon the company's next earnings release is expected. It helps identify an approaching report that may bring new information about the business. For example, 5 days means the expected release is five calendar days away. Calendar dates are estimates unless confirmed by the company.

## How is calculated?

`expected earnings date − today's UTC date`, in calendar days.

For an expected date window, use the first day of the window. Recalculate the days remaining on each load using a source collected within the last seven days. Missing, invalid, past or same-day events hide the metric.

## Tags

- **This week:** the expected release is 1–7 days away.
- **Next 30 days:** the expected release is 8–30 days away.
- **Later:** the expected release is more than 30 days away.

These tags describe timing. Unavailable dates do not display an Unknown card.
