# Industry Relative Strength

## What it means?

_How has the stock's industry performed compared with the wider market?_

Compares the equal-weight one-year price return of tracked industry peers with the broad-market benchmark, excluding the selected stock from the peer basket.

## How is calculated?

`equal-weight tracked peer 1Y price return − market benchmark 1Y price return, pp`.

Use reviewed industry classifications, at least five eligible other companies and matching comparison dates and currencies. Exclude the selected stock. Returns are price returns excluding dividends. Each peer has equal weight. The selected stock versus industry return is supporting context. The historical chart shows the tracked-industry indexed return minus the benchmark indexed return from the same comparison start; no Ahead/In-line/Behind classification is applied.

## How to interpret it?

Sparse peers, a selected universe, classification differences and date or currency gaps can distort the comparison. Review both absolute returns; relative performance can be positive while prices fall.

This is a contextual metric. It has no deterministic classification rules or tags and does not participate in saved-filter matching, rankings or automatic scores.

## Display and history

Available in the expandable **Contextual metrics** section of stock details. The card opens its question, description, calculation, reporting dates, source identifiers and explanatory notes. Values and charts use neutral styling. Missing values remain unavailable, never zero.

The chart shows Tracked industry minus market (pp since comparison start). Plot only available comparable historical observations. Annual year-end valuation points and quarterly observations must keep their stated basis; neither is silently relabeled as current TTM data.

Source identifiers preserve provenance, not independent verification. See the [metric index](../README.md).
