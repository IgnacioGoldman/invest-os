## How to write recommendation

- Use short, plain titles without a "Codex" prefix. Examples: "Allocation Review", "Buy Candidate Search", "Sell / Trim Review".
- Treat the recommendation type as a small tag next to the title, not repeated inside the title.
- Put the important summary before the chat: one clear headline plus a few practical bullets.
- Do not ask the frontend to show separate metric boxes like "Priority" or "Type"; the app already has status and type tags.
- Keep the full reasoning in the chat body. The chat can stay collapsed by default, because the summary is the primary user-facing view.
